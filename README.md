## Update and build

`resume.json` is the source of truth. The site uses JSON Resume and the Stack Overflow theme; the current theme reads project descriptions from `summary`, so keep `description` and `summary` in sync.

```sh
npm ci
npm test
npm run build
```

The build generates `public/index.html`. Preview it locally:

```sh
python3 -m http.server 8000 --directory public
```

Open <http://localhost:8000>. Do not hand-edit the generated HTML.

Pull requests validate and build the resume. Production deployment to Netlify runs only on pushes to `master`.

The checked-in `Souvik Maji.pdf` is a historical export; it is not regenerated by the website build. To create a current PDF, build the website and use the browser’s Print / Save as PDF option.
